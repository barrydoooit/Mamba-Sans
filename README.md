## 安装说明

前往 [**Releases**](../../releases) 下载 `.ttf` 字体文件：

- **Windows**：右键 `.ttf` 文件 → **安装**
- **macOS**：双击 `.ttf` 文件 → **安装字体**
- **Linux**：将 `.ttf` 复制至 `~/.local/share/fonts/` 并执行 `fc-cache -fv`
