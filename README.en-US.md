## Installation

Download `.ttf` files from [**Releases**](../../releases):

- **Windows**: Right-click `.ttf` → **Install**
- **macOS**: Double-click `.ttf` → **Install Font**
- **Linux**: Copy `.ttf` to `~/.local/share/fonts/` and run `fc-cache -fv`
