## 安裝說明

前往 [**Releases**](../../releases) 下載 `.ttf` 字體檔案：

- **Windows**：右鍵點擊 `.ttf` 檔案 → **安裝**
- **macOS**：雙擊 `.ttf` 檔案 → **安裝字體**
- **Linux**：將 `.ttf` 複製至 `~/.local/share/fonts/` 並執行 `fc-cache -fv`
